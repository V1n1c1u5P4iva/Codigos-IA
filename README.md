# TCC — Inteligência Artificial Generativa no Desenvolvimento de Software: Qualidade Estrutural e Corretude Funcional de Código Gerado por LLMs

Repositório com os códigos utilizados no Trabalho de Conclusão de Curso (TCC) do curso de Ciência da Computação da **Universidade Estadual do Piauí (UESPI)**.

**Título do trabalho:** Inteligência Artificial Generativa no Desenvolvimento de Software: Qualidade Estrutural e Corretude Funcional de Código Gerado por LLMs

**Autor:** Vinicius Paiva

## Sobre este repositório

Aqui estão os códigos gerados por LLMs e utilizados no estudo de caso do TCC, comparando duas estratégias de prompting (zero-shot e Chain-of-Thought) em uma aplicação com backend em Python e frontend em React. Os códigos foram avaliados quanto à qualidade estrutural (SonarQube) e corretude funcional (suíte de testes manual).

Este material é parte de um trabalho acadêmico individual e está disponibilizado apenas para fins de consulta e referência.
